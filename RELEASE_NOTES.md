# Role DeepSeek 1.1.0-beta

Первая публичная **beta**-сборка нативного Android-приложения для ролевых чатов в DeepSeek.
В этой версии починен главный вылет (добавление фото), добавлены настройки производительности
и исправлена ещё дюжина багов, найденных при ревизии кода.

> **Это beta.** Приложение работает, но обкатывается: часть сбоев ещё ловится и правится по ходу.
> Метка «beta» видна прямо в шапке библиотеки и на экране настроек.

---

## 📦 Что в этом релизе

| Файл | Для чего |
|---|---|
| `RoleDeepSeek-debug.apk` | готовый APK, ставится на телефон (debug-подпись, ставится рядом с release) |
| `RoleDeepSeek-release.apk` | подписанная release-сборка (R8 + shrinkResources) — если приложена |

**Требования:** Android 8.0+ (API 26). Разрешения на галерею и хранилище **не нужны**.

**Установка:** скопируйте `.apk` на телефон → откройте файловым менеджером → разрешите установку
из неизвестных источников. `applicationId` debug-сборки — `com.pythonistavp.roledeepseek.debug`,
поэтому debug и release спокойно уживаются на одном устройстве.

## 🆕 Главное

- **Починен вылет при добавлении фото.** Экран обрезки uCrop (`UCropActivity`) не был объявлен
  в манифесте, и `startActivity` падал с `ActivityNotFoundException`. Теперь всё объявлено,
  а весь путь «фото → кроп → аватар» обёрнут в обработку ошибок и не роняет приложение.
- **Выбор фото без разрешений** — системный `PickVisualMedia` вместо доступа к галерее,
  плюс съёмка на камеру (снимок через FileProvider, кроп 1:1).
- **Настройки производительности** — три профиля в один тап (**Качество / Баланс / Экономия
  батареи**) и тонкая ручная настройка: колонки сетки, размер и качество сохраняемых аватаров,
  миниатюры в списках, BlurHash-превью, crossfade картинок, кэш в памяти (5–50 %) и на диске
  (32–512 МБ), локальная статистика. Кэш Coil перестраивается на лету.
- **Меньше вылетов по памяти (OOM)** — большие фото декодируются с понижением (`inSampleSize`),
  аватары масштабируются при сохранении, BlurHash-превью живут в отдельном LRU-кэше.
- **Быстрее списки** — фильтрация, поиск и сортировка библиотеки выполняются вне главного потока.

## 🔧 Полный список изменений

### Исправленные падения
- Вылет при добавлении фото (`UCropActivity` отсутствовал в манифесте).
- Плавающая подсказка падала с `SecurityException` на **любом Android 9+** — в манифесте не было
  разрешения `FOREGROUND_SERVICE`.
- Падение на Android 14 (`targetSdk 34`) из-за отсутствующего `android:foregroundServiceType`.
- Виджет мог упасть с `TransactionTooLargeException` — аватар для `RemoteViews` не влезал
  в лимит Binder (~1 МБ). Теперь он декодируется с уменьшением до 128 px.
- В системной ночной теме стартовое окно было светлым и мелькало белым.
- При повороте экрана приложение повторно открывало чат/редактор из виджета или «Поделиться».

### Исправления данных
- **Создание папки с занятым именем** сносило старую папку (`INSERT OR REPLACE`) вместе
  с привязкой персонажей. Теперь операция аккуратно отклоняется с сообщением.
- **Переименование** папки в занятое имя падало с `SQLiteConstraintException` — тоже исправлено.
- **Черновик редактора** больше не «воскресает» после сохранения или удаления персонажа,
  и принудительно сохраняется при выходе с экрана.
- Удаление персонажа корректно сбрасывает его как «любимого» для виджета.
- На чистой установке сетка показывала 1 колонку вместо 2, а ползунок обещал 5 колонок,
  тогда как сетка рисует максимум 4. Теперь значения по умолчанию и границы согласованы.

### Прочее
- Убрана лишняя зависимость `accompanist-permissions` — приложение стало немного легче.
- Метка **beta** в шапке библиотеки и в настройках, встроенный changelog и раздел «О приложении»
  с честной пометкой, что сборка сделана с ИИ.
- В настройках добавлены очистка кэша Coil, сброс настроек, очистка статистики и временных файлов.
- Бэкап всей библиотеки теперь сохраняет и настройки производительности; старые бэкапы
  читаются без ошибок.

## 🔒 Приватность

Вся библиотека хранится **только на устройстве** (Room + внутренние файлы + DataStore).
Приложение не содержит рекламы, не требует аккаунта и не собирает телеметрию. Единственный
сетевой сценарий — загрузка аватара по ссылке из чужой карточки при импорте (лимит 12 МБ).

---

## ⚠️ Известные ограничения

- DeepSeek не даёт публичного API для вставки текста в чат, поэтому промпт копируется в буфер
  обмена, а чат открывается отдельно — вставить нужно вручную (или через плавающую подсказку).
- Плавающая подсказка требует разрешения «Поверх других окон» и включается переключателем
  на экране запуска чата.
- Скриншоты в `docs/screenshots/` — плейсхолдеры.
